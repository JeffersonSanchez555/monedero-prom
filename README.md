# Caja de Comentarios (JavaScript + CSS)

Sistema completo de comentarios en el navegador con funcionalidades CRUD (Crear, Leer, Editar, Eliminar).

## Funcionalidades
- **Crear:** Publica nuevos comentarios.
- **Editar:** Modifica el texto de cualquier comentario existente.
- **Eliminar:** Borra comentarios individuales.
- **Persistencia:** Todo se guarda en `localStorage` para no perder la información al recargar o cerrar la página.

## Instrucciones de Ejecución
1. Extrae el contenido de este archivo ZIP.
2. Haz doble clic en el archivo `index.html`.
3. La aplicación se abrirá en tu navegador web por defecto sin necesidad de servidor ni Python.
